**Status:** APPROVED plan · 2026-08-24

## 1. Research basis

Three specialist briefs informed this plan (summaries archived in
`~/.hermes/profiles/librarian/cache/delegation/`, 2026-08-24):

- **AGE/Postgres brief**: PG11–18 × AGE 1.7.0 officially supported; Microsoft's AGE
  performance guide prescribes GIN on `properties` + BTREE `id` + edge BTREEs on
  `start_id`/`end_id`; MERGE-heavy upserts are a known slow path (apache/age#2177) — batch them;
  thin own Dockerfile over unaudited all-in-one images; build HNSW after bulk load.
- **Hermes internals brief** (repo @4553e71993, v0.20.5): full MemoryProvider ABC contract
  with call sites; discovery requires `__init__.py` containing `register_memory_provider`
  or `MemoryProvider`; prefetch hard timeout 8s; distribution via plugin dir AND pip entry
  point `hermes_agent.memory_providers`; `get_config_schema()` powers `hermes memory setup`.
- **Testing brief**: hypothesis-tester skill conventions; seam inventory; 8 property tests;
  testcontainers for ephemeral DB; Ollama stubbed out of PR CI.

Two items flagged UNVERIFIED by specialists were resolved empirically against the running
stack: `gin_agtype_ops` opclass works on this AGE build; GIN indexes are the correct
mechanism for MATCH-by-property.

## 3. Interface contracts (fixed — cards must not drift these)

### 3.1 Provider (implements Hermes `MemoryProvider`, repo @4553e71993)

| Method | Contract |
|---|---|
| `name` | `"hybrid-age"` |
| `is_available()` | No network calls. Check config resolvable + driver importable. Set `unavailable_reason()` otherwise. |
| `initialize(session_id, **kwargs)` | Accept `**kwargs` always (Hermes adds kwargs regularly). Skip writes unless `agent_context=="primary"`. |
| `prefetch(query, *, session_id="") -> str` | Sync. Never raises. Return `""` on any failure. Read from pre-warmed cache filled by `queue_prefetch`. Budget <2s typical; Hermes kills at 8s. Output = fenced block ≤1200 tokens. |
| `sync_turn(user_content, assistant_content, *, session_id="", messages=None)` | Enqueue only; returns immediately. Background drain does embed + inserts. Queue maxsize 256; drop + count on overflow. |
| `on_memory_write(action, target, content, metadata=None)` | Keep `metadata=None` kwarg exactly (signature introspected upstream). Mirror to memory_entries. |
| `get_tool_schemas()` | Bare OpenAI function schemas; `normalize_tool_schema` wraps upstream. |
| `get_config_schema()` / `save_config(values, hermes_home)` | Required so `hermes memory setup` works. Secrets → env_var fields (.env); behavior knobs → config.yaml keys under a `hybrid_age:` block. |
| `shutdown()` | Drain queue ≤5s, close pool. |

Threading: methods called synchronously from turn threads; own the asyncio loop pattern
from the current working plugin (dedicated loop thread + `asyncio.run_coroutine_threadsafe`).

### 3.2 Config surface

```yaml
# ~/.hermes/config.yaml
hybrid_age:
  dsn_env: HYBRID_AGE_DSN            # secret/endpoint → env only
  embed_url_env: HYBRID_AGE_EMBED_URL
  embed_model: nomic-embed-text      # behavior knob → yaml
  graph: hermes_knowledge
  vector_k: 12
  min_similarity: 0.55
  max_tokens: 1200
memory:
  provider: hybrid-age               # activation key (agent_init.py:1873)
```

Resolution order: yaml > env > defaults (matches existing packaged provider docstring).

### 3.3 Store layer rules

- Every Cypher statement inside SAVEPOINT; failed statement rolls to savepoint, never poisons txn.
- MERGE on minimal unique key (`{name}` or `{path}`), non-key props via `ON CREATE SET`/`ON MATCH SET`.
- Batch MERGEs (≥50/txn) per apache/age#2177.
- Vertex IDs crossing into JS/UI: stringify (bigint precision).
- Embeddings: vector(768) everywhere; `embed()` returns None (never wrong-dim vector) on failure.

## 4. Database schema & indexes (C2 deliverable)

Tables carry over from the proven local schema (`conversations`, `messages`, `sessions`,
`memory_entries`, `doc_chunks`, `memory_chunk_nodes`, `librarian_runs(+events)`,
`schema_migrations`) — extractor-ready columns included now (`processed_at`,
`relations_processed_at`, `processing_attempts`, `last_error`).

Index DDL (authoritative):
```sql
-- relational
CREATE INDEX ... ON memory_entries USING hnsw (embedding vector_cosine_ops) WITH (m=16, ef_construction=64);
CREATE INDEX ... ON memory_chunk_nodes (vertex_id, graph_name);
CREATE INDEX ... ON memory_chunk_nodes (source, chunk_id);
CREATE INDEX ... ON conversations (ts) WHERE processing_attempts >= 5;          -- dead letter
CREATE INDEX ... ON conversations (ts) WHERE processed_at IS NULL
  AND content IS NOT NULL AND length(content) > 20;                             -- queue
CREATE INDEX ... ON conversations (relations_processed_at) WHERE relations_processed_at IS NULL;
CREATE INDEX ... ON memory_entries (agent_identity, ((metadata->>'file_path')))
  WHERE agent_identity = 'librarian';

-- AGE vertex labels (Person Project Technology Organization Concept Domain Skill Tool Repo
--    File Module Dependency Standard Session Turn): per label,
CREATE INDEX ... ON hermes_knowledge."<Label>" USING BTREE (id);
CREATE INDEX ... ON hermes_knowledge."<Label>" USING GIN (properties ag_catalog.gin_agtype_ops);

-- AGE edge labels: additionally
CREATE INDEX ... ON hermes_knowledge."<Edge>" USING BTREE (start_id);
CREATE INDEX ... ON hermes_knowledge."<Edge>" USING BTREE (end_id);
```
Generate programmatically post-`create_graph`. Build HNSW after bulk load, not before.
Compose healthcheck: `pg_isready -U $POSTGRES_USER -d $POSTGRES_DB`.

Docker image: thin Dockerfile `FROM apache/age:release_PG17_1.7.0` +
`apt-get install postgresql-17-pgvector` (verify tag exists on Hub first — C2 acceptance item).

## 6. Property test register (from testing brief)

| ID | Test | Guards |
|---|---|---|
| P1 | Cypher string escape: no unescaped `'`/`\` survives `age_str` over any st.text() | injection/poison bug class |
| P2 | age_props: None dropped, keys preserved exactly once | malformed MERGE props |
| P3 | capitalized-phrase extraction: no `\n` spans, ≤45 chars, deduped | extractor noise |
| P4 | phrase normalization idempotence | concept self-replication |
| P5 | module-name heuristic rejects artifacts (hex/uuid/digits/skip-dirs) | the 146-garbage-Module bug |
| P6 | dependency extraction deterministic, sorted, unique | nondeterministic index output |
| P7 | file-hash + state roundtrip; corrupt JSON → {} | silent state corruption |
| P8 | backfill dedup key `(lower(name),label)` uniqueness + bridge insert/delete symmetry | orphan bridges |
